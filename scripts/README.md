# 辅助脚本

- `validate.mjs`：检查版本、许可证、清单、Skill 文件及包内引用，不访问 GitHub、不修改运行数据。
- `secrets.mjs`：先只读预览 `.env` 中的 Secret 名称，再按已确认的主机、仓库、账号和确认摘要提交。只支持单行 `KEY=VALUE`、可选 `export`、单/双引号和注释；双引号支持 `\n`、`\r`、`\t`、`\\`、`\"`，不展开变量或执行命令。

Secret 名称统一为大写，大小写重复名称和 `GITHUB_` 保留名称会被拒绝。每批最多 100 项，文件最多 1 MiB，每个值最多 48 KiB；不支持物理跨行值，遇到未支持格式应修正文件后重新预览。符号链接和非普通文件不接受。

预览只输出目标、账号、名称及确认摘要 `sha256`；摘要绑定主机、仓库、账号、名称和原始文件字节，不能跨目标复用。应用前会重新读取文件、核实目标和当前账号，并重算同一摘要。值仅经标准输入交给 `gh`，不进入命令参数或输出；只有 `gh` 返回成功才计入 `completed`。失败或中断可能已写入，返回 `unknown` 后必须核对，既不自动重试，也不尝试恢复不可读取的旧值。

脚本不存储凭据或预览状态，不修改本地 Secret 文件，也不声称构成文件沙箱。操作仍受宿主 Shell 工具授权和 GitHub 账号权限控制。新增可执行辅助放在这里，回归测试放在 `../__test__/`。
